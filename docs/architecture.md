# 架构与边界

前端 React SPA 通过 `/api` 调用 FastAPI。开发时由 Vite 代理到 127.0.0.1:8000；后端直接调用 MaaS，key 仅在后端环境变量中。后端 SQLAlchemy 用于初始化和结构读取；SQL 执行用独立 SQLite DBAPI 只读连接加强权限控制。

请求链路：ChatRequest → question/history → MaaS 查询计划 → JSON解析 → SQL AST校验 → 表白名单 → SQLite authorizer + mode=ro + 3秒超时 → 最多200行 → 可选MaaS分析 → ChatResult。

`analyze=false` 时只执行查询，不发起第二次分析请求。分析只基于本次返回的数据；截断会提示范围。历史最多6轮且不含 key。基础版由勾选项控制分析，不自动检测文本里的“分析”意图；演示时请勾选“生成业务分析”。当前为非流式响应，前端显示查询中状态。

接口稳定扩展点是 `chart`。图表由 CodeArts Agent 开发，初始版 null。MaaS 未配置时后端仍启动、初始化数据库、提供场景信息和健康状态；不伪造自然语言查询成功。

数据库启动仅初始化空库，seed=42 固定随机数。已有数据库只校验场景表集合，不迁移数据。无会话持久化，刷新即清空对话；历史保存在浏览器组件内存，最多12条消息传给后端。

云库未来可通过独立适配器接入，必须替换 SQLite 专属权限、日期方言和超时机制，并使用只读数据库用户。当前对非 SQLite URL 明确报错。
